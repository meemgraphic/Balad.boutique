# Balad Boutique website
Static site (no build step).

**Netlify:** drag the `balad-site` folder onto app.netlify.com/drop, or connect your Git repo (build command: none, publish directory: `.`).
**GitHub Pages:** push these files to a repo, then Settings > Pages > deploy from branch `main` / root.

Edit products in `index.html` (array `P`) and swap photos in `assets/img/`.
